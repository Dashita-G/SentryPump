# SentryPump
AI-Powered Petrol Station Safety Monitoring System
SentryPump is a computer vision–based prototype designed to support safer petrol station environments by identifying potentially hazardous activities, tracking movement in monitored areas, and assisting with vehicle license plate recognition.

Developed by Team Tech Titans, the project brings together object detection, multi-object tracking, license plate recognition, a local database, and 3D visualization in a single application concept.

The Problem:

Petrol stations require continuous attention to safety risks. Relying entirely on manual observation can make it difficult to monitor multiple areas at once, especially when activity levels are high. SentryPump explores how computer vision can help flag events for review and organize related monitoring data.

Proposed Solution:

An AI-Powered Hazard Detection, Suspicious Activity and Loitering System that integrates automated subsidy enforcement and a 3D interactive monitoring dashboard.
